 Admin Panel Features (Login-Protected):
Daily Stock Management:

Admin sets the available stock for each dish at the start of every day.

Previous day's stock and bookings should be closed and view-only for reference (archived, not editable).

Display a summary of yesterday’s stock usage and revenue.

Dish Management:

Add / Edit / Delete dishes (with name, price, description, image)

Show all dishes like Chicken Mandi, Fish Mandi, Mutton Mandi etc. on the main dashboard with:

Dish Name

Price (in ₹ Indian Rupees)

Available Quantity

Booked Quantity

Remaining Quantity

When admin books 2 Chicken Mandis from 50 stock, dashboard should immediately show 48 left.

Pop-up confirmation should appear before deleting a dish.

Booking Module:

Admin books a dish by filling customer name, contact, and dish selection.

Automatically decrease available stock when a booking is made.

Block booking for dishes with 0 stock (mark as “Out of Stock”).

Revenue Tracking:

Show total revenue:

Daily (today’s total)

Monthly

Yearly

Date-wise filter

Revenue calculated as: dish price × number of bookings.

Export Booking Data:

Allow download/export of booking data as CSV or Excel file

Include: customer name, contact, dish, price, booking time
